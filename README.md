# Portfólio Pessoal

Projeto de portfólio pessoal desenvolvido como atividade acadêmica para praticar os fundamentos de **HTML e CSS**.

## Sobre o projeto

O site apresenta informações profissionais, formação, projetos de programação e formas de contato.

O objetivo é desenvolver uma página web estruturada semanticamente e estilizada utilizando apenas HTML e CSS.

## Tecnologias utilizadas

* HTML5
* CSS3


## Páginas

* **Início:** apresentação pessoal.
* **Currículo:** formação, experiência, cursos e competências.
* **Projetos:** apresentação dos projetos desenvolvidos.
* **Contato:** links para GitHub, LinkedIn e outros canais profissionais.

## Contexto

Projeto desenvolvido para a disciplina de desenvolvimento web da faculdade.
